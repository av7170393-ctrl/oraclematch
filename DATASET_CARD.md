# ratings_synthetic.csv: SYNTHETIC dataset (not real user data)

Generated by `src/make_synthetic_ratings.py` (seed 7). Schema follows MovieLens: `userId, movieId, rating, timestamp`,
where `movieId` is the TMDB id of the film in `tmdb_5000_movies.csv`.

- 2,000 simulated users, 140,440 ratings, 4,586 films rated, density 1.46%, mean rating 3.5 (0.5 to 5.0 in half steps)
- Each user has hidden tastes (genre affinity, favourite era, strictness, some like non-English films)
- Users tend to watch popular films that match their taste; rating = taste match + film quality + user bias + noise

## Use and limits
- Good for: building and testing the pipeline (collaborative filtering, hybrid, evaluation code).
- NOT good for: claims about real-world performance. The signal in the data is whatever the generator put in it.
- Do not present this as real data (resume, interviews, README). Say "synthetic ratings".

## Swap in real data later
Download `ml-latest-small.zip` from grouplens.org. Join `ratings.csv` with `links.csv` (movieId -> tmdbId),
keep columns `userId, tmdbId as movieId, rating, timestamp`, and save as `data/ratings_synthetic.csv`
(or change the path in `evaluate_cf.py`). Rerun `python src/evaluate_cf.py`.
